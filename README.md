# Thaki — legal & support pages

The published Privacy Policy, Terms of Use and Support pages for
**Thaki: Goal Trails** (iOS).

Served by GitHub Pages at <https://mustafayevt.github.io/thaki-legal/>:

- [Privacy Policy](https://mustafayevt.github.io/thaki-legal/privacy.html)
- [Terms of Use](https://mustafayevt.github.io/thaki-legal/terms.html)
- [Support](https://mustafayevt.github.io/thaki-legal/support.html)

These are the pages the app's Settings rows and the Trail Pro subscription
screen link to, which App Review requires to be reachable (App Store Review
Guidelines 5.1.1 and 3.1.2).

This repository is public **only** so GitHub Pages can serve it for free —
the app itself is closed-source. The HTML is generated from the markdown
sources in the app repo (`docs/product/legal/`), which remain the single
source of truth. Edit there, regenerate, push here.
