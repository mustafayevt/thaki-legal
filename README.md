# Thaki — legal and support pages

The public Privacy Policy, Terms of Use and Support pages for **Thaki** (iOS), plus a small home page.

Served by GitHub Pages at <https://mustafayevt.github.io/thaki-legal/>:

- [Home](https://mustafayevt.github.io/thaki-legal/)
- [Privacy Policy](https://mustafayevt.github.io/thaki-legal/privacy.html)
- [Terms of Use](https://mustafayevt.github.io/thaki-legal/terms.html)
- [Support](https://mustafayevt.github.io/thaki-legal/support.html)

The app and App Store Connect link exactly `privacy.html`, `terms.html` and `support.html`, so keep those file names.

The pages are self-contained static HTML (inline CSS, no scripts, no external fonts). They are generated from the drafts
in the app repo, `web/src/content/legal/en/` (`privacy.md`, `terms.md`, `support.md`), with the 2026-10-19 founder
decisions applied: no domain, one contact address (mustafayev.t@outlook.com), Sign in with Apple as the only sign-in,
and the seller named as an individual developer in Baku, Azerbaijan. The drafts in the app repo stay the source of
truth: edit there, regenerate, then push here.

This repository is public only so GitHub Pages can serve it for free; the app itself is closed-source.
